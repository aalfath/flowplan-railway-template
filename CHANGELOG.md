# Changelog

Every change to this template's `main` branch reaches people who deployed it as an "update available" notice on Railway. Breaking changes are listed first.

## 0.11.4 (2026-11-24)

- First release of the template: Flowplan 0.11.4 (`ghcr.io/yannicschuller/flowplan:0.11.4`, pinned by digest), SQLite and uploads on a Railway volume at `/app/data`, administrator created on first boot from `ADMIN_EMAIL` / `ADMIN_PASSWORD`, memory caps for 0.5 GB services.
